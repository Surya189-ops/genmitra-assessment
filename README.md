# GenMitra Assessment

This is my submission for the Frontend Developer Intern technical assessment at GenMitra Technologies.

The project is a simple multi-vendor shopping page where users can add products from different stores to one cart.

## What I built

- Product listing with the given mock data
- Add products to cart
- Increase/decrease quantity
- Remove items from the cart
- Products from different stores can be added to the same cart
- Cart items are grouped by store
- Total items and price update automatically
- Sticky cart bar at the bottom
- Separate cart view
- Cart is saved in localStorage, so it stays after refreshing the page
- Mobile-friendly layout

## Tech used

- Next.js
- React
- TypeScript
- Tailwind CSS
